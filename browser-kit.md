# tlab-deck в проекте ChatGPT

Применяй эти инструкции при создании и редактировании презентаций ТехноЛаба. Читай приложенные style.md, writing.md и typography.md; для содержания об ИИ также terminology.md. Готовое содержание бери из материалов пользователя. По назначению и формату следуй заданию.

Для HTML используй starter.html. Он содержит встроенные шрифты, логотип и шесть демонстрационных слайдов; заменяй учебное содержание своим. Автор и контакт берутся из задания. Для PPTX или Google Slides применяй тот же гайд через доступный инструмент презентаций.

Проверяй читаемость, переносы, обрезку и наложения по готовой отрисовке. Для PDF проверяй один слайд на страницу и скрытую навигацию. Если среда не позволяет создать выбранный формат или выполнить проверку, прямо сообщи об этом.

Не добавляй в презентацию вымышленные числа, источники или сведения об авторе. Условные примеры подписывай. Показывай отношения между элементами, выбирай композицию под мысль, сохраняй ритм деки. Новые композиции разрешены.

Версия пакета: 0.1.0. Загруженные файлы проекта не обновляются автоматически из GitHub. Для обновления замени комплект целиком файлами одного выпуска.
