# technolab-team

При запросе презентации в стиле ТехноЛаба прочитай [tlab-deck](skills/tlab-deck/SKILL.md) и действуй по его правилам. Формат и содержание определяются заданием пользователя.

Папка скилла переносима: инструкции, ресурсы и вспомогательные скрипты находятся в `skills/tlab-deck/`. Для запуска проверки и PDF-экспорта смотри `SKILL.md`.

Этот репозиторий — результат сборки исходного пакета ТехноЛаба. Предложения изменений оформляются в Issues; новая версия выходит из источника сборки.
