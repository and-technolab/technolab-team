# technolab-team

Инструменты команды **ТехноЛаб АНД** для совместной работы с ИИ.

Первый скилл — **`tlab-deck`**: создание и редактирование презентаций в стиле ТехноЛаба. В комплекте — гайд, автономный HTML-шаблон с шестью примерами, встроенные шрифты и логотип, проверка типографики и экспорт в PDF.

Версия пакета: **0.1.0**. [Скилл](skills/tlab-deck/SKILL.md) · [Гайд стиля](skills/tlab-deck/references/style.md) · [HTML-шаблон](skills/tlab-deck/assets/starter.html) · [Скачать комплект](https://github.com/and-technolab/technolab-team/releases/latest).

## Подключить в Codex

Самый короткий путь — попросить встроенный Skill Installer:

```text
$skill-installer установи tlab-deck из репозитория
and-technolab/technolab-team, папка skills/tlab-deck
```

В новом сообщении выбери `$tlab-deck`. Если скилл не появился, перезапусти Codex. Доступен и общий плагин: добавь этот репозиторий как каталог командой `codex plugin marketplace add and-technolab/technolab-team`, затем открой `/plugins` и установи `technolab-team`. Для прямой установки скилла каталог плагинов не нужен.

## Подключить в ChatGPT Desktop / Work

Для локального проекта скачай репозиторий или клонируй его, открой эту папку как проект, перезапусти приложение и найди каталог «ТехноЛаб · Команда» в Plugins. Установи `technolab-team`, затем выбери скилл `tlab-deck` через `@`. Доступность локальных каталогов зависит от версии приложения.

Если используется Codex, можно установить отдельный скилл через Skill Installer, как описано выше. [Официальные способы подключения](https://learn.chatgpt.com/docs/build-skills).

## Подключить в общем workspace ChatGPT

Администратор открывает **Admin → Plugins → Add → Import marketplace** и указывает:

- Source: `https://github.com/and-technolab/technolab-team`
- Path: оставить пустым
- Branch: `main` для обновлений или `v0.1.0` для фиксированной версии

После импорта нужно разрешить установку плагина нужным участникам. Импорт и синхронизация из GitHub требуют прав администратора и доступа к репозиторию. [Официальная инструкция](https://learn.chatgpt.com/docs/enterprise/plugin-management).

## Использовать в ChatGPT в браузере

Если установка плагинов недоступна, создай проект «Презентации ТехноЛаба». Скачай из последнего выпуска `tlab-deck-chatgpt.zip`, распакуй его и загрузи файлы в источники проекта. В инструкции проекта вставь:

> При создании и редактировании презентаций применяй приложенные правила tlab-deck. Сначала прочитай browser-kit.md и гайд стиля. Используй мои материалы как источник содержания. Формат результата учитывай из задания. Для HTML используй starter.html. Проверяй готовые слайды и сообщай, если среда не позволяет выполнить визуальную проверку или экспорт.

Наличие файла на GitHub само по себе не подключает его к ChatGPT. Загруженные файлы проекта обновляются вручную; при новом выпуске замени их файлами той же версии. [Как работают источники и инструкции проектов](https://learn.chatgpt.com/docs/projects).

## Первый запрос

```text
Используй tlab-deck. Подготовь презентацию по приложенным материалам.
Аудитория: руководители компаний. Цель: объяснить предложение и следующий шаг.
Объём: 6 слайдов. Формат: HTML и PDF.
Автор: [имя и контакт]. Числа и утверждения бери из моих материалов.
```

Для редактируемого PowerPoint прямо укажи **PPTX**. В скилле есть правила стиля, но отдельный PPTX-шаблон в этот выпуск не входит. Результат и возможность экспорта зависят от инструментов, доступных в твоём ChatGPT.

## О ТехноЛаб АНД

ТехноЛаб — площадка Ассоциации независимых директоров по искусственному интеллекту: место, куда первое лицо идёт за суждением об ИИ в управлении. За тем, как бывает на самом деле, а не как должно быть в теории.

Повестка вышла из зоны ИТ-директора в повестку совета — капитальные затраты, риски и данные, продуктивность функций, оценка качества менеджмента. А в матрице компетенций директора про искусственный интеллект нет ничего, и без собственного суждения директор теряет главное своё умение: задавать менеджменту правильные вопросы. Площадка достраивает эту матрицу слоем ИИ и работает в трёх направлениях — личная эффективность руководителя, ИИ в стратегическом управлении, поддержка ИИ-трансформации.

Форматы разные: онлайн-оценка зрелости, разборы кейсов и мастермайнды, двухдневные интенсивы, шестидневная программа подготовки операторов ИИ-трансформации, корпоративное обучение и сопровождение внедрения. Здесь мы выкладываем инструменты, которые собираем для участников.
