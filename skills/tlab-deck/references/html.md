# HTML и экспорт

## Шаблон

`assets/starter.html` — самостоятельный файл с шестью демонстрационными слайдами, встроенными шрифтами и официальным логотипом. Скопируй его в папку результата. Меняй содержимое, оставляя оболочку и правила печати.

- `.slide` — холст 1280 × 720. Уникальный `id` позволяет ссылаться на кадр через `#s2`.
- `.slide-head` — метка раздела и счётчик; `.slide-foot` — автор или организация.
- `.content` — область содержания. Поля и шрифты заданы CSS-переменными.
- `.cover` — тёмная обложка; `.panel` — тёмный смысловой акцент.
- `window.tlabDeck.go(index)` — показать слайд по индексу с нуля. `window.tlabDeck.count` — число слайдов. `window.tlabDeck.ready` — Promise загрузки шрифтов и изображений.
- Стрелки, PageUp/PageDown, Home/End и экранные кнопки управляют показом. Свайп работает по горизонтали.

Композиции демонстрации: обложка, один тезис, сравнение, маршрут, таблица и итог. Расположение элементов можно менять под задачу.

## Печать в браузере

Открой HTML, выбери печать и сохранение в PDF. Масштаб — 100%, поля — отсутствуют, фон — включён, колонтитулы браузера — выключены. После сохранения открой PDF: один кадр на страницу, без пустой последней страницы и без навигации.

## Автоматический экспорт

После установки зависимостей, перечисленных в `SKILL.md`, запусти `scripts/render.mjs` с путями к HTML и папке результата. В папке появятся `slide-01.png` и следующие кадры, `deck.pdf`, `report.json`.

Можно указать существующий Chrome или Chromium:

```bash
node <skill>/scripts/render.mjs <deck.html> <output-directory> --browser /path/to/chromium
```

Для проверки нужны доступ к локальным файлам и возможность запуска браузера. Скрипт завершает работу с ошибкой при незагруженном фирменном шрифте, сетевых ресурсах, ошибках JavaScript или найденном переполнении. Для произвольной HTML-деки с другой оболочкой адаптируй экспорт к её устройству.
