# Стиль ТехноЛаб

Применяй к презентациям и страницам АНД AI по запросам «в стиле АНД», «в стиле ТехноЛаба», «как наши деки». Тема AIST с Commissioner, Inter и синим `#0048B2` сюда не переносится.

## Композиция и визуальный смысл

1. **Сначала мысль, затем форма.** Определи, что зритель должен понять. Заголовок и содержимое раскрывают одну мысль или вопрос.
2. **Показывай отношения.** На объясняющем слайде расположение элементов помогает увидеть зависимость, сравнение, движение, выбор или изменение. Раскладки текста по блокам для этого может быть недостаточно.
3. **Выбирай композицию под содержание.** Таблица полезна для сопоставления, схема — для связей, маршрут — для последовательности. Списки и спокойные текстовые слайды допустимы по задаче. Готовый аналог не обязателен.
4. **Создавай иерархию.** Задай зрительный центр и порядок чтения. Масштаб, положение, начертание и контраст показывают важность. Равный вес элементов оправдан их равной ролью.
5. **Используй цвет по смыслу.** Обозначай им роль, выбранное состояние, разрыв или результат. Сохраняй значение обозначений внутри деки. Тёмная панель — возможный акцент, а не обязательный блок каждого слайда.
6. **Графика выполняет работу.** Иконка, линия, заливка или мокап помогают понять содержание. Числа, изображения и примеры берутся из источников; условные примеры явно помечаются.
7. **Воздух поддерживает фокус.** Выбирай ширину, плотность и расстояния вокруг главного. Компактная композиция допустима; пустое место само по себе не требует заполнения.
8. **Сохраняй ритм деки.** При смене смысловой задачи пересматривай композицию. Повторяй макет, когда повторяется задача сравнения или чтения. Цельность держат шрифты, оси, палитра и обозначения.

Новые композиции и графические обозначения разрешены. Локальное замечание не становится запретом на целый класс решений. При прямой просьбе скопировать конкретный слайд сохраняй его композицию, графику и типографику, меняя только оговорённое.

## Типографика презентаций: ориентиры и свобода

Размеры — CSS px на холсте 1280 × 720. Назначай кегль по смысловой роли текста. Это отправные точки: осмысленные отступления выбирай самостоятельно и проверяй отрисовкой.

| Роль | Старт / обычный диапазон | Шрифт и вес |
|---|---|---|
| Обложка, название раздела | 48 / 44–64 | Unbounded 200–300; акцент 400–500 |
| Заголовок слайда | 36 / 34–38; плотные рабочие деки 30–34 | Onest 300; акцент 600 тёмно-синим |
| Название блока | 20 / 18–22 | Onest 500–600 |
| Короткий лид, отдельный тезис | 22 / 18–24 | Onest 400–600 |
| Обычный текст и пояснения | 16 / 14–17 | Onest 400; акцент 600 |
| Содержательная подпись, таблица | 15 / 13–16 | Onest 400–600 |
| Метка, дата, счётчик, источник | 12 / 11–13 | JetBrains Mono 400–500 |
| Главная цифра | 48 / 32–64 и крупнее по задаче | Unbounded 200–300 |

- Не увеличивай основной текст глобально до 18–20 px ради заполнения холста. При увеличении текста пересматривай его объём и композицию.
- Одинаковые роли текста должны ощущаться согласованными. Крупная цифра, тезис и справочное пояснение могут иметь разный масштаб.
- Интерлиньяж: заголовок 1.12–1.25, название блока 1.2–1.35, абзац 1.35–1.55. Для служебных меток — прописные и разрядка около `.14em`.
- Метка раздела остаётся компактной и второстепенной. Даты, диапазоны и короткие слова со следующим словом склеивай; при тесноте пересматривай формулировку и место.
- Диапазоны и средний кегль не являются автоматическим критерием качества. Проверяй фактически загруженный шрифт, переносы и читаемость в размере показа.

## Палитра и форма

| Роль | Значения |
|---|---|
| Основной фон | `#FFFFFF` |
| Основной текст, чернильная панель | `#0A1628` |
| Тёмно-синий акцент | `#12294D` |
| Пояснения / служебные подписи | `#4B5260` / `#646C78` |
| Латунь: кромки, линии, метки | `#A98A4B` |
| Латунный текст: на белом / на тёмном | `#846832` / `#C9AD72` |
| Светлые подложки | `#EEF2F8`, `#F4F5F7`; тёплый итог — `#ECE5D7` |
| Видимая рамка / внутренний разделитель | `#B9BEC7` / `#C9CED6` |

- Палитра сдержанная. Латунь используй дозированно. Различимость ролей поддерживай также положением, формой и подписью.
- Значимые линии, рамки и подписи должны быть видны в размере показа. Второстепенный текст сохраняет читаемость, в том числе на тёмных заливках.
- Геометрия плоская, углы прямые, без теней. Круги и точки допустимы; в изображениях интерфейсов сохраняй узнаваемую форму оригинала.
- Характерный приём — латунная черта около метки, ориентир 34 × 2 px. Её положение выбирается по композиции. Кромка панели или карточки — обычно 2–3 px.
- Панель может использовать `linear-gradient(150deg, #24508F 0%, #12294D 70%)`.
- Обложка — светлый логотип АНД · ТехноЛаб и белый Unbounded на `radial-gradient(120% 140% at 85% 0%, #24508F 0%, #12294D 45%, #0A1628 100%)`.

## Экран и служебные элементы презентации

| Элемент | Расположение и поведение |
|---|---|
| Холст | 1280 × 720; пропорциональный масштаб `min(ширина / 1280, высота / 720)` |
| Фон | Закрывает всё окно при любом соотношении сторон; содержимое сохраняет пропорции |
| Основные оси | Ориентир: поля слева и справа 84 px, верх содержимого 54 px |
| Раздел и счётчик | Вверху справа: ориентир `top:28px; right:36–38px` |
| Автор | Внизу слева по оси содержимого: имя и контакт автора из задания; если их нет — подпись организации, без вымышленного авторства |
| Навигация | Точки или меню снизу по центру, кнопки справа; поверх слайда, без отдельной пустой полосы |
| PDF | Интерактивные элементы скрыты; автор, счётчик и содержание сохранены |

## Частные форматы

- Для повторяющихся схем одного процесса сохраняй роли и обозначения между слайдами.
- Если у заказчика есть отдельные цвета статусов или условные обозначения, используй их последовательно.
- В мокапах чатов и постов сохраняй узнаваемые элементы оригинала. Метрики и содержание не выдумывай.

## Проверка перед сдачей

1. Мысль и структура ключевого кадра считываются за несколько секунд; форма помогает понять связь между его частями.
2. В полном размере читаются текст, подписи и графика; нет случайных переносов, наложений и обрезки.
3. На ленте слайдов видны иерархия и ритм; новые кадры воспринимаются как продолжение выбранных эталонов.
4. После правки существующей деки сравни до и после. Проверяй весь кадр, включая метки и служебные элементы.
5. Экран и PDF проверены отдельно: фон без белых полей, навигация не перекрывает содержание, шрифты и счётчики на месте.
